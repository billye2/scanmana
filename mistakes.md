# Mistakes log

Convention: every fixed mistake gets an entry here in the same change that fixes it.
Format: `- YYYY-MM-DD — what went wrong — how it was fixed / how to avoid it`
- 2026-09-07 — HANDOFF.md recorded another product's infrastructure (its database name, the shared Vercel project id, leftover env var names), which blocked making the repo public. Fixed: scrubbed the docs, moved those notes to private memory, squashed git history. Lesson: per-repo docs describe only that repo; cross-project infra notes go in private memory.
- 2026-09-03 — the empty-deck hint still said "tap Run scan **above**" two releases after the button moved below the deck (1.0.5). Fixed alongside the rename to "Run scan for previous day". Lesson: when a control moves, grep for prose that points at it.
- 2026-09-02 — the 02:30 UTC (9:30pm ET) cron never did any work: Massive's grouped-daily bars for the day are not published by then, so every night it fell back to the previous day, saw "already scanned", and the 05:30 UTC catch-up did the real scan. Fixed: first cron moved to `0 4 * * 2-6` (midnight EDT). Lesson: verify a cron actually wrote rows (`scan_results.created_at`), not just that it returned 200.
- 2026-09-01 — the analysis verdict had a "Take" level, but the app only ever sees end-of-day bars: by the time a breakout is visible the session is over, so "buy now" is never a decision the data supports. Fixed: `Verdict` is `wait | pass`; breakout-day branches say "buy tomorrow's open if it holds". Lesson: verdict vocabulary must match what the data can actually decide.
- 2026-09-01 — charts never rendered on the deck: `Chart` div was `h-full` inside a flex-1 parent under a `min-h-dvh` main, so its percentage height resolved to 0 and lightweight-charts was created 0px tall. Fixed: chart div is `absolute inset-0` in a `relative` flex-1 parent, plus `autoSize: true` with a 300px fallback. Lesson: percentage heights need a definite ancestor height; verify UI in a browser, not just by curl.
- 2026-09-01 — first manual scan failed: Massive free tier returns 403 "Attempted to request today's data before end of day" for the current ET date, and `fetchGroupedDaily` threw instead of walking back to the previous trading day. Fixed: that specific 403 is treated as "no data yet" (empty), so `runScan` falls back a day. Also added a 05:30 UTC catch-up cron (skips if already scanned) in case 02:30 UTC is before Massive's cutoff.
- 2026-08-31 — backfill died at 192/261 dates on a transient `SocketError: other side closed` from Massive; `lib/massive.ts` `get()` had no retry, so one dropped socket killed a 55-min job. Fixed: `get()` retries transient errors/5xx with backoff (2s→16s) and waits out 429s; 4xx stay fatal. Backfill was already resume-safe, so nothing was lost.
- 2026-08-31 — setup wizard and `vercel env pull` wrote secrets (API key, DB URLs, CRON_SECRET, VAPID private key) into `.env.local`. Policy is Vercel-env-only (`~/.claude/CLAUDE.md`). Fixed: wizard adds the key straight to Vercel; `npm run dev|migrate|backfill|scan:now` wrap in `vercel env run -e production`; dotenv removed from scripts; `.env.local` stripped to public VAPID values.
- 2026-08-31 — scripts loaded env via `dotenv/config`, which reads `.env` only, while Vercel pulls secrets into `.env.local` — DB scripts saw no DATABASE_URL. Fixed with `config({ path: [".env.local", ".env"] })`; only Next.js itself auto-loads `.env.local`, plain Node scripts never do.
- 2026-08-31 — deployed to the existing `rc02` Vercel project without first checking what its production alias served; it replaced an unrelated earlier deployment. Fix going forward: before the first `--prod` deploy onto a pre-existing Vercel project, inspect its deployments/aliases and confirm with the user. (Rollback path documented in HANDOFF.md.)
